# Geological Everything Model 3D

Project website: https://douyimin.github.io/GEM/

**Unified Interactive Inference through Target-Conditioned Representations**

This repository hosts the static research project page. Serve the repository
with any static HTTP server; no build or package installation is required.




- Page: `index.html`
- Styles and interactions: `static/css/gem.css`, `static/js/gem.js`
- Current manuscript: `static/papers/GEM_English_NCS.pdf`
- Overview and standalone result gallery: `static/images/*.png`
- Video posters: `static/images/posters/`

The arXiv link and BibTeX refer to the earlier 2025 preprint. The current
manuscript is provided separately and includes Supplementary Information.
